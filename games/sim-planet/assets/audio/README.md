# Sim Planet Audio Assets

Music files in `music/` are local exports moved from Downloads for personal use:

- `tiny-solar-run.mp3`
- `orbital-drift.mp3`
- `tiny-solar-run-2.mp3`
- `orbital-drift-2.mp3`

The game treats these as a calm continuous playlist. Music unlocks on first player interaction, keeps playing across boot, running, and paused states, and crossfades instead of cutting hard between tracks.
