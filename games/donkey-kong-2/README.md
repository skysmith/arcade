# Donkey Kong Jr.

Vine-heavy Donkey Kong Jr.-style cabinet for the local arcade shelf.

Current setup:

- single-screen rescue stage with keys, chains, vines, and moving hazards
- `1-4` local players
- first controller becomes `P1`, extra pads can join live with `Start`
- keyboard fallback for solo testing
- compact HUD with immediate start and one obvious back path

Controls:

- Keyboard fallback: `Left` / `Right` move, `Up` / `Down` climb, `Space` jump, `P` pause, `R` restart
- Controller: d-pad or left stick move and climb, south button jumps, `Start` joins or pauses

Goal:

- collect the keys on the vine routes
- carry them into the lock gates
- break all three chains
- touch the cage platform to finish the rescue
