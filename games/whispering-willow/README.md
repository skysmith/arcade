# Whispering Willow

Peaceful story-adventure branch built from the shared arcade travel shell.

Current status:

- controller-first menu flow, map progression, authored threads, and up to four local travelers remain intact
- combat pressure is softened into crossing guidance, recovery work, route notes, voiced messages, and lantern-pulse signaling
- random hostile traffic and battle-style crossing encounters are disabled for this branch
- the action/battle fantasy stays in its sibling cabinet

Design direction:

- keep the world calm, mysterious, and emotionally warm
- make contacts and voiceovers feel like the main reward
- turn danger into confusion, weather, lost cargo, tense crossings, and social choices rather than fighting
- preserve enough shared structure that future improvements to maps, menus, save flow, and controllers can still carry across both games

- build and conversion notes: `FOREST_BUILD_PLAN.md`
