# Forest Build Plan

Practical conversion plan for turning the `Jumpwake` mechanics shell into `Whispering Willow`.

## Reuse Intact First

- controller-first dock/menu flow
- map progression structure
- contact thread UI
- detail-card image system
- save slots and state persistence
- lightweight authored mission/arc framework

## Re-theme Next

- sectors -> forest locations
- ships -> party roles, creatures, or travel modes
- cargo/contracts -> errands, remedies, charms, offerings, rescue work
- boarding/combat events -> creature encounters, bramble hazards, goblin scuffles, spirit disturbances
- factions -> woodland communities, innfolk, goblin clans, river spirits, old wardens
