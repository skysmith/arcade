# snow-bros

Shared-screen Snow Bros style co-op cabinet for the local arcade shelf.

Current setup:

- single-screen snow arena with layered platforms and short wave clears
- `1-4` local players
- first controller becomes `P1`, extra pads can join live with `Start`
- keyboard fallback for solo testing
- enemies can be packed with snow, then kicked into rolling snowballs

Controls:

- Keyboard fallback: `Left` / `Right` move, `Up` jump, `Space` throw snow, `P` pause, `R` restart
- Controller: d-pad or left stick move, south button jumps, east or west throws snow, `Start` joins or pauses

Goal:

- tag enemies with snow until they freeze solid
- kick frozen enemies to start a rolling snowball
- chain through the rest of the wave
- clear the room to advance to the next peak
