# detective

This is an Game Studio project.

Template: `platformer`
Theme prompt: a calm, quiet, easy explorer game, 2d side scroller.

Primary files:

- `index.html` bootstraps the preview shell
- `style.css` controls the studio presentation
- `game.js` contains the main interactive behavior

Keep the game previewable in the browser after every change.
Prefer small, readable iterations over large rewrites.
