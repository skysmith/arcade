# Jumpwake

Controller-first space-sandbox vertical slice built from the repo's remake planning docs.

Current slice:

- Docked command deck with gamepad-friendly menu navigation
- Cargo market and procedural contracts
- Eight connected sectors with distinct prices, legality, and faction pressure
- Top-down flight, combat, interdiction, docking, and hyperspace
- Disable, board, loot, and capture flow
- Captured ships become light escorts and can be sold at port

Controls:

- Keyboard: `WASD` or arrows to steer, `Space` confirm/fire, `Shift` secondary, `Tab` map, `Esc` back/pause
- Controller: left stick or d-pad steer, south confirm/fire, west secondary, east back, start pause, north starmap

Design bias:

- Menus and interactions should feel good on a pad first
- Dock flow should stay legible without a mouse
- The slice favors the "one run turns into a ship capture" fantasy from the spec
